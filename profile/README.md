### offramp

[**offramp**](https://github.com/devopsgenie-ai/offramp) is our free, MIT-licensed audit. It reads your repository and reports exposed Supabase data, leaked keys and platform lock-in. It runs on your machine and sends nothing anywhere.

```bash
git clone https://github.com/devopsgenie-ai/offramp
python3 offramp/skills/offramp/scripts/audit.py path/to/your-app --out audit-report
```
